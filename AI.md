# AI

This document describes how AI is used in this project and
what is expected from contributors.

## How AI Is Used in This Project

The technical design of the Datapages framework is **entirely human-authored**.
AI tools were used to generate and review parts of the codebase and documentation,
but not to make architectural or design decisions.

User-facing content and APIs are always reviewed before being published.
Internal AI-generated code is reviewed as thoroughly as time constraints allow.

## Contributing with AI

You are welcome to use AI tools when contributing to this project.
However, all issues and code changes **must be manually reviewed and understood**
by the person submitting them. Unreviewed AI-generated contributions —
whether copy-pasted from a chatbot or submitted by an automated bot —
will be declined. A human in the loop is expected.
